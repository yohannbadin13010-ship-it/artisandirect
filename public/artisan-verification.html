Comment ça fonctionne ?

1. Vous préparez vos justificatifs.
2. ARTISANDIRECT contrôle automatiquement les informations lorsque c'est possible.
3. Les dossiers suffisamment fiables peuvent être validés automatiquement.
4. Les cas incertains sont orientés vers un contrôle humain.
5. Le badge ✓ Vérifié n'est affiché qu'après validation.

🔒 Protection des données : cette version de démonstration ne demande pas encore le dépôt de vrais justificatifs. N'envoyez aucun document personnel ici tant que le stockage sécurisé et les règles d'accès n'ont pas été finalisés.
